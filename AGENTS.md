# AGENTS.md

Laravel 13 + React 18 (Vite) app for ancientcitiesturkey.com. PHP 8.3, Node 24 (`.node-version`), MySQL 8.

## Commands

CI (`.github/workflows/pipeline.yml`) runs in this order — mirror it before pushing:

```bash
npm run build        # must run before PHPUnit (see gotchas)
vendor/bin/phpunit   # sqlite :memory:, no MySQL needed
./vendor/bin/php-cs-fixer fix --dry-run --using-cache=no
./vendor/bin/phpstan analyse --no-progress --memory-limit=1G
```

- Single test: `vendor/bin/phpunit --filter test_name`, or pass a file path.
- Local dev: `docker compose up -d` (php-fpm + nginx :80 + mysql), then `npm run dev` for the Vite server.

## Gotchas

- **Feature tests need a Vite build first.** `resources/views/app.blade.php` uses `@vite` and `/public/build` is gitignored, so on a fresh clone PHPUnit fails with a manifest-not-found error until `npm run build` has run. This is why CI builds assets before testing.
- Docker Compose exposes MySQL on host port **3307** (not 3306); database `ruins`, user/pass `ruins`/`secret`. Containers use `DB_HOST=mysql`.
- `MAPBOX_ACCESS_TOKEN` (.env) is injected as `window.mapboxToken` in the Blade layout; without it the map renders blank with no error.

## Architecture

- Blade shell + React 18 SPA mounted on `#root` (`resources/js/app.jsx`). React Router mirrors the Laravel routes: `/:language?/:ruin?`.
- Every web and API route is locale-prefixed (`/{locale}/...`); `App\Http\Middleware\SetLocale` (registered in `bootstrap/app.php`, Laravel 11+ style — no HTTP kernel) sets the app locale from the route param.
- Bilingual data: `Ruin` stores English in `name`/`information` and Turkish in `name_tr`/`information_tr`. Accessors in `app/Ruin.php` make `$ruin->name` return the Turkish value when locale is `tr`; writes still go to the plain columns.
- `Ruin` binds routes by **slug** (`getRouteKeyName`), slugs generated by eloquent-sluggable from `name`.
- Saving a `Ruin` fires `RuinSaved` → `ResizeRuinImage` listener rescales images >350KB via Intervention Image (needs ext-gd).
- Artisan commands: `links:check`, `sitemap:generate`, `app:get-cities`.

## Style

- php-cs-fixer over `app`, `routes`, `tests`: PSR-12 plus short arrays, no Yoda, one space around `.` concatenation (`.php-cs-fixer.dist.php`).
- Larastan level 5 over `app` and `routes`.
- Translations in `resources/lang/{en,tr,es,he,pl,ru,zh-CN}`; `tr` is the default/fallback locale.
